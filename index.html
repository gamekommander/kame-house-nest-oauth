Personal smart home integration

Kame House

A personal-use integration connecting the owner's Nest thermostat to Home Assistant.

What it does

Kame House uses Google's Smart Device Management API to read authorized thermostat information and to adjust temperature settings and operating modes for personal home automation. Access requires the owner's explicit Google authorization.

Who it is for

This integration is for the owner's own use. It is not a public sign-up service. This website provides information about the integration; it does not sign users in, receive OAuth callbacks, or operate any devices.

Privacy

Thermostat data and authorization credentials belong in the private integration, never in this website or its public source repository.
