Privacy policy

Your home data stays private.

Effective October 13, 2026.

Scope and operator

Kame House is a personal-use Nest thermostat integration operated by the owner of the GitHub account gamekommander. This policy covers the private integration and this public informational website. The integration is not offered as a service for other users.

Data accessed and purpose

With the owner's authorization, the integration uses Google's Smart Device Management API to access the authorized home's structure and device identifiers, device and room names, and thermostat information such as temperature, humidity, target temperatures, operating mode, and heating or cooling status, where available. It may receive device-state events through Google Cloud Pub/Sub.

The integration uses this information to display thermostat status and run the owner's home automations. It sends authorized commands to Google to adjust thermostat settings. OAuth access and refresh tokens are used to maintain this authorized connection. Kame House does not request access to Gmail, Google Drive, contacts, or calendars for these thermostat functions.

Storage and retention

Authorization credentials and device data are handled by the owner's private Home Assistant installation and the Google services needed for the integration. Device history, logs, and backups may retain data according to the owner's Home Assistant and backup settings. This policy does not promise a fixed retention period or immediate deletion of existing backups.

The public website and source repository contain no OAuth tokens, client secrets, private installation addresses, or private device records. The website does not receive or store Nest data.

Sharing and limited use

Data is used for the owner's thermostat integration and is exchanged with Google as needed to authorize access, obtain device information, receive events, and send commands. Kame House does not sell Google user data, use it for advertising, or transfer it to data brokers. It does not use Google user data to train generalized artificial intelligence or machine learning models.

Kame House's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This website and hosting

This is a static website hosted by GitHub Pages. It adds no analytics scripts, tracking pixels, cookies, forms, or browser storage. GitHub may process visitor information, such as IP addresses and request metadata, to provide and secure hosting under its privacy statement. Following external links is subject to the destination's privacy practices.

Revoking access and deleting data

The owner can revoke the connection through Nest Partner Connections Manager and review access through Google Account connections. Revoking access stops future authorized access; it does not automatically erase previously stored history, logs, or backups. Remove the integration and its stored credentials from Home Assistant, and separately delete retained records and backups if deletion is desired.

Questions and updates

For non-sensitive questions, contact the maintainer through the repository's issues page. Issues are public: do not post credentials, home details, device data, or personal information. For private support, use the support email shown on the Google OAuth consent screen, if present.

This policy will be updated if the integration's data practices change. The effective date above identifies the current version.
